# Expo SDK version

This project is pinned to Expo SDK 54 (see `expo` in package.json). Read the
exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code — check this file against `package.json`'s `expo` version
whenever the SDK is upgraded, since a stale version number here will send
future sessions to docs for APIs that don't match what's actually installed.
